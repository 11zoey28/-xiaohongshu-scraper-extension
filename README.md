# -xiaohongshu-scraper-extension
基于 Claude Code 开发的浏览器插件，推荐使用Chrome浏览器，可以自动抓取小红书笔记互动数据并生成分析报告

## 项目背景
在实习期间负责竞品内容分析工作，需要人工打开、记录、比对大量小红书笔记的互动数据，效率低且难以沉淀规律。为解决这一问题，基于 Claude Code 独立开发了这款浏览器插件，实现数据抓取与分析的自动化。

## 核心功能
- 自动抓取指定小红书账号/笔记的互动数据（点赞、评论、收藏、发布时间等）
- 从手动逐条点选，迭代为关键词匹配自动填充，按需注入 content script
- 自动生成互动率分析报告，辅助内容策略判断

## 技术栈
- Chrome 浏览器插件（Manifest V3）
- JavaScript / Content Script 注入
- 基于 Claude Code 完成迭代开发

## 使用说明
1. 在 Chrome 中打开 `chrome://extensions/`，开启右上角"开发者模式"
2. 点击"加载已解压的扩展程序"，选择本项目文件夹
3. 打开小红书网页版，点击插件图标即可开始抓取
